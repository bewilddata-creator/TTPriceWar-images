# TTPriceWar-images

Backup copies of TT Price Wars product images: `img/<barcode>.jpg`, max 300px, white background.
The barcode is normalised (digits only, leading zeros stripped) — the same key the app uses.

Written only by `tools/backup-images.mjs` in the TTPriceWar repo. Don't edit by hand.
`manifest.json` records the source URL each file was made from.
